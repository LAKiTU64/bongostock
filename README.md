# BongoStock

一只记录你敲了多少键盘、点了多少鼠标的桌面猫，顺手把自选行情、资讯和视频收进同一个浮窗。BongoStock 是供个人使用的 Windows / macOS 紧凑桌宠（Tauri 2 + Vue 3），不联网也能计数，行情与视频走自建网关。

- 当前版本：`1.2.0`
- 公开仓库：<https://github.com/LAKiTU64/bongostock>
- 默认分支：`main`
- 变更记录：[CHANGELOG.md](CHANGELOG.md)
- 安装包：`1.2.0` 的 Windows x64 NSIS 与 macOS Apple Silicon DMG 均未做代码签名/公证；macOS 为 ad-hoc 签名，首次打开需右键 →「打开」放行。上一版 `1.1.0` 见 [GitHub Release 1.1.0](https://github.com/LAKiTU64/bongostock/releases/tag/1.1.0)

## 桌宠

### 计数与反馈

- 键盘按下、鼠标点击各自累计，计数只存本机；
- 鼠标、键盘、左右猫爪提供动作反馈；同一只爪同时只显示最后按下的键位图层；
- 计数框按最多 9 位数 `999 999 999` 设计；
- 透明、无边框、可拖动窗口，支持托盘、窗口穿透、透明度、保持在屏幕内、开机自启动；
- 尺寸可在 50%～300% 之间连续调节；
- Windows 下部分系统级按键收不到释放事件，超过「按键自动释放延迟」后视为已释放；
- 需要更稳定地捕获系统级按键时，可以管理员身份运行；首次会说明原因，可选择「不再提示管理员权限」。

### 位置与找回

- 启动时把桌宠放回上次的位置，可以放在副屏，也可以横跨相邻屏幕；
- 原位置超出当前可用工作区（拔掉外接屏、改分辨率、重排显示器）时，就近移回可见范围；macOS 在接拔或重排显示器后也会重新检查；
- 托盘与桌宠右键菜单提供「找回桌宠与浮窗」：把桌宠和**已存在**的浮窗移到鼠标所在显示器的工作区，无法确定时用主屏。显示桌宠时保持原有置顶、缩放、透明度与穿透设置；隐藏或未打开的浮窗不会被打开，也不会恢复播放或声音。

### 模型与皮肤

- 内置两套 MMmmmoko 模型，均为与 [Awesome-BongoCat](https://github.com/ayangweb/Awesome-BongoCat) 兼容的 Live2D 目录结构：`builtin:mmmmmoko`（经典小键盘 · 标准模式，含鼠标垫、键盘、鼠标反馈与标准键位）、`builtin:mmmmmoko-keyboard`（经典小键盘 · 键盘模式，含左右爪与键位图层）；
- 复用原版 BongoCat 的背景、Live2D 与键位叠图坐标体系；BongoStock 自己的计数框与 SVG 菜单框始终在模型下方；
- 自定义外观通过本地 `.bongoskin` / ZIP 包导入，当前支持 `layered-png-v1`（左右爪各有静止与拍下图层）。导入器限制包大小、文件数量、单文件大小与路径，拒绝目录穿越和可执行内容；
- 私人皮肤不在本仓库、不在内置资源、不在 Git 历史中，也不会进入公开构建；未取得明确再分发许可前不得上传或打包。

## 设置与快捷键

设置分六个页签：**通用、连接、样式、行情、视频、关于**。

- **通用**：开机自启动、任务栏图标（开启后可被 OBS Studio 捕获）、托盘图标、主题模式（跟随系统/亮色/暗色）、界面语言、自动检查更新，以及 macOS 的辅助功能/输入监控授权入口；
- **样式**：皮肤与模型、镜像模式、鼠标镜像、忽略鼠标事件、窗口穿透/置顶/保持屏内/尺寸/圆角/不透明度、动作音效、动作与表情、按键自动释放延迟、鼠标移入隐藏、最大帧率，以及浮窗的常驻模式与后台保留时间；
- **行情**：自选分组与证券管理、拖动排序、云端同步状态；
- **视频**：扫码登录、查询状态、切换账号、退出；
- **关于**：版本与诊断信息（可一键复制用于提 issue）、查看日志、检查更新、开源地址、鸣谢与第三方声明；
- **快捷键**：打开猫咪、打开偏好设置、镜像模式、窗口穿透、窗口置顶、老板键，支持单键与组合键。

老板键默认留空。绑定后一键关闭**设置和浮窗**并停止视频播放，桌宠保持原来的显示状态。macOS 允许「输入监控」后，外接键盘的 CAL（计算器）、Menu、PrtSc、Scroll Lock、Pause、邮件等扩展键也可用。

## 行情与自选

### 浮窗行为

- 点击桌宠打开独立行情浮窗；首次打开或临时状态回收后按桌宠当前位置重新定位，优先显示在下方，空间不足显示在上方；
- 顶栏整行可拖动：轻点按钮执行操作，按住移动超过 4 个逻辑像素即拖动浮窗；
- **隐藏浮窗**（顶栏右侧划线眼睛）：保留期内点击桌宠可恢复同一个浮窗，位置、置顶状态、当前页面和播放器都保留。后台保留时间在「样式 → 浮窗」设置，范围 1–1440 分钟、默认 60 分钟，每次隐藏开始计时；到期关闭浮窗并停止播放，再点击桌宠从行情页打开；
- **常驻模式**在「普通」「置顶」「置顶且不透明」间切换。普通模式点击外部关闭并停播，页面与位置默认保留 30 秒（时长可在「样式 → 浮窗」调整）；置顶时点击外部保留浮窗，置顶且不透明时也不淡出。按 Esc 直接关闭并清除临时状态，下次从普通模式开始；
- 默认无操作 2 秒后淡出至 28% 不透明度，等待时间与淡出程度均可调；
- 打开或手动刷新时请求一次报价，浮窗关闭时不轮询。

### 自选管理

- 最多 8 个分组，全部分组合计最多 300 只沪深股票、指数或场内基金；按去重后的证券数计上限，同一只证券可同时属于多个分组；
- 列表为紧凑双栏布局；支持 `SH600036`、`SZ000858` 与 6 位纯数字代码，纯数字按沪深规则补交易所并在线匹配名称；
- 新数据默认建「自选股」分组，含上证指数、深证成指、沪深 300、科创 50；
- 客户端「行情」与 Web 自选管理页都能拖动分组手柄调整分组顺序，或在选中分组内拖动证券排序；连续排序按版本串行保存，长列表支持边缘自动滚动；
- 点击证券按需加载分时、5 日、日 K；图表悬停显示时间/日期与价格，日 K 同时显示开高低收。

### 云端同步

- v2 采用时间戳增量拉取（随行情请求顺带检查 `since`）、2 秒防抖推送与串行上传，用 `baseUpdatedAt` 乐观锁检测多终端冲突；
- 本地有待上传修改时，迟到的拉取和旧上传结果不会覆盖这些修改；遇到 409 保留本地修改、暂停自动重试，并提示手动选择拉取云端或推送本地；
- Web 管理页保存失败或冲突时回滚到已确认的云端状态并报错；云端为空而本地有数据时自动迁移，迁移冲突不清空本地；
- 每次写入自动快照（最多 10 份），可通过 Web 管理页或 API 一键回滚，回滚结果自动同步到客户端。

## 资讯

- 提供全市场、简报、个股三个范围，个股范围联动本地自选分组与证券；
- 使用内置主题，也可右击搜索按钮临时输入完整检索词；不保存搜索历史或检索词；
- 时间范围 1 天 / 3 天 / 7 天 / 不限，按发布时间倒序；召回档位约 10 条或约 20 条。主题、时间、条数使用自定义按钮与弹出菜单（不用系统原生下拉样式），支持方向键、Home/End、Esc、Tab；筛选行固定保留搜索按钮宽度，菜单限制在浮窗内；
- 只在点击搜索或顶部刷新时请求，不后台轮询；
- 数据只经 BongoStock Gateway 转发，客户端不直连上游、不保存上游 API Key，也没有本地资讯回退；
- 点击条目在同一浮窗内打开完整内容页，可返回列表或用系统浏览器打开原文；已读条目在本机淡化显示。

## 刷视频

「刷视频」页有推荐、每周必看、排行、关注、历史、收藏六个标签，不提供视频搜索。

### 卡片与翻页

- 固定两列一行，每页两张等宽等高卡片；统一底栏左侧显示收藏夹名或每周必看期号，右侧固定 `‹ 页码 ›`（只显示数字）。首尾不循环，末页只有一条时保留右侧空位；
- 卡片保留 16:9 封面、两行标题、一行作者；封面左下显示播放量、右下显示时长，播放量用 `123`、`2345`、`1.1w`、`108w` 简写；历史卡片左下改为 `P2 · 12:34` 或 `P2 已看完`，不额外占进度行。卡片间距与卡片到底栏间距均为 6px，底栏固定 24px；
- 收藏夹名/期号/错误重试/翻页共用一行，不单独占状态行；长收藏夹名在入口截断、展开后换行；加载失败不改变卡片与底栏尺寸，也不阻止切换收藏夹；不显示常规加载、云端进度更新或过滤说明；
- **鼠标滚轮**每次事件翻一页，向下前进、向上返回，不累计距离；
- **macOS 触控板**按原生滚动距离累计：同方向累计 20 个逻辑像素翻第一页，之后每再滑 50 个逻辑像素翻一页，余量保留；可连续翻页，无需抬手；反向滑动或重新起手从 20 重新起算；抬手后的惯性不翻页。切换账号、来源、收藏夹、期数、播放器或窗口可见性会清除未完成手势，普通翻页不清除累计距离。收藏夹与期数菜单要等原生拦截撤销后才打开，关闭后恢复卡片翻页；
- 非 macOS 或原生监听不可用时退回 DOM 滚轮逻辑，不保证识别触控板惯性；
- 页面即时切换，卡片不因滚动或动画被禁用；仅等待尚未取得的下一页时暂停前进，不积压后续翻页；主动刷新替换列表期间暂不翻页，完成后恢复，避免旧页码覆盖新列表。按钮可连点；不支持按住卡片拖动翻页，也不接管播放器、顶部栏和缩放手势。

### 分页与缓存

- 展示页与服务端分页独立，普通来源按每批 20 条请求，临近缓存末尾预取；
- 下一页未就绪时保留当前卡片和页码，不积压更多翻页；失败后按钮重试，滚动不会自动重发，已缓存页仍可前后浏览，不显示猜测的总页数；
- 当前组件会话内各来源分别记住卡片顺序、页码与服务端游标，切换来源或从播放返回不重置，主动刷新成功才回当前来源第一页、失败保留原内容；
- 缓存仅存在内存，账号或连接变化后全部作废。

### 每周必看

- 默认打开最新一期；点击底栏期号向上展开期数列表，按新到旧排列并显示上游给的日期名称，列表可滚动，支持方向键、Home/End、Esc、Tab，菜单内滚动不翻视频页；
- 左右箭头只翻当前期的视频，各期独立保留缓存与页码；刷新更新期数目录和当前期视频，不自动跳回最新期，成功才回当前期第一页，失败保留已有内容；
- 请求 `GET /v1/feeds/weekly/issues` 与 `GET /v1/feeds?source=weekly&weeklyNumber=N`，返回的 `weeklyNumber` 必须与选中期数一致，缺失或不匹配时拒绝加载，不混期；期数接口不可用时显示错误与重试，不猜期号也不回退到别的期。

### 收藏与历史

- 「收藏」只读当前账号自己创建的收藏夹（含私密夹），不提供增删。首次进入默认打开第一个收藏夹，点击底栏收藏夹名向上展开切换；长名称换行、列表可滚动，支持方向键、Home/End、Esc、Tab。每夹分别记住视频顺序和页码，切夹/切来源/播放返回都不重置。主动刷新先更新收藏夹列表，当前夹仍存在则保留，否则选第一个；列表或视频加载失败保留已读卡片与页码，视频刷新成功才回第一页。无收藏夹、空夹、未登录、加载失败分别提示；
- 收藏接口需要网关实现 `GET /v1/bili/favorites/folders?mid=...&revision=...` 与 `GET /v1/bili/favorites/videos?mid=...&revision=...&folderId=...&page=1`；客户端校验账号、登录版本、收藏夹、页码与响应结构，账号失效或变化时撤销旧缓存并重新确认身份。仅在进入该标签或手动刷新时读收藏夹，不为其他来源额外发收藏请求；
- 「历史」只显示 B 站云端账号历史，按观看时间取每个视频最近观看的分 P。列表只缓存在内存，读取失败保留已加载条目并可重试；未登录时引导登录，网关不支持账号身份时明确提示更新，不回退到本地记录；
- 续播只使用云端返回的同视频同一 P 进度，并用播放器实际 P 时长校验（不用视频总时长）。已看完、或距结尾不足 5 秒（短视频不足时长 5%）时从头播放。首次进入历史页读云端列表；从播放器返回时重新读取最近记录，只更新缓存卡片的分 P 与进度，不改变排列、视觉页码或分页游标；云端新排序在主动刷新或新会话中生效；
- 登录后实际播放约每 15 秒经网关上报进度，暂停、切 P、结束尽力补报；上报不阻塞播放，失败退避且不重发旧快照。观看时长只累计 playing 状态的墙钟时间，不计暂停、缓冲、seek，也不按倍速放大。断网、异常退出或上游延迟时最后一段进度可能丢；
- 客户端不再读写或合并本地观看记录，也不提供本地记录入口与清空操作；旧版已存文件保持原样，不主动删除或上传。云端账号历史没有删除操作；
- 换账号、重登、改网关或令牌会停止旧播放、清掉临时账号缓存并撤销旧上报队列。账号接口基于社区资料而非官方稳定开放 API，跨设备同步效果取决于上游服务。

### 播放与声音安全

- 点击卡片在浮窗内播放。只有在**确认当前输出是耳机且设备监听正常**时才默认开声；扬声器、未知输出或查询失败一律默认静音。仍可手动静音或开声（含扬声器），开声前重新确认输出，查询失败保持静音；
- 只提供播放/暂停、静音/开声、进度条、倍速、返回列表，不提供全屏、画中画或音量滑块。标题与控制条覆盖在视频上，鼠标移入显示、移出隐藏，键盘操作或展开选集时保持可见。倍速按 1× → 1.5× → 2× → 0.75× → 1× 轮换，切 P 保留倍速。多 P 视频另有选集入口，播完一 P 停止，不自动续播；
- macOS 可能请求蓝牙权限，用于判断当前蓝牙输出是否为耳机；不扫描、不配对、不主动连接。拒绝权限或无法判断类型时保持静音。系统音频路由通知是异步的，这一保护不保证硬件切换过程中零漏音；
- 输出变化时立即静音并暂停，保留播放位置；重新接上耳机不自动恢复播放或声音，需手动操作。切 P 复用当前声音意图，但每次播放前重新检查输出；无法建立设备监听时禁用默认开声，仍可显式手动开启；
- 主动隐藏浮窗期间正在播放的视频继续播放，音量、静音、倍速、分 P 沿用当前设置，已暂停的保持暂停；耳机断开仍会静音并暂停。返回列表、切换页面或关闭浮窗会停止播放；
- 列表、封面、扫码登录和视频字节流全部经过已配置的 Gateway；JSON 请求走 Tauri 请求通道，客户端不保存 B 站 Cookie。登录凭据保存在网关，连同一网关的客户端共用一个 B 站账号；
- 未登录可看游客推荐、每周必看与排行，关注/历史/收藏需登录。上游排行不可用时改显示热门视频，底栏左侧标为「热门」，正常排行不加额外筛选栏；
- 实际视频与画质取决于上游可用性和账号权限；二维码过期或登录失效需重新扫码。

## 行情网关

BongoStock **不内置任何行情数据源**。报价、搜索、分时/5 日、日 K 全部来自外接的 BongoStock API v1：

```text
GET  /v1/capabilities
POST /v1/quotes      # 每批最多 25 个代码
POST /v1/search
POST /v1/trends
POST /v1/klines      # 前复权
```

首次使用在「连接」填入 token 即连上默认网关 `https://123.57.156.148`；自建网关可改服务地址，超时 1～30 秒。正式构建把 Token 存入系统凭据库，开发模式存本机配置文件（避免重编译反复请求钥匙串授权）；正式版迁移旧配置时先确认系统凭据写入成功再清除旧字段，失败则保留原配置。未配置可用服务时行情不可用。

资讯额外使用 `POST /v1/news/search`，视频使用 `/v1/feeds*` 与 `/v1/bili/*`，都经同一网关。完整约定见 [`docs/EXTERNAL_MARKET_API_V1.md`](docs/EXTERNAL_MARKET_API_V1.md)。代码放在 POST body 只减少 URL 与访问日志暴露，HTTP 仍是明文，HTTPS 也挡不住网关自己看到代码。所有数据仅供个人辅助参考，不能替代券商终端。

Tauri 2 · Vue 3 · TypeScript · Pinia · Rust stable · Vite · PixiJS · easy-live2d

## 本地开发

需要 Node.js、pnpm、Rust stable 和目标平台的 Tauri 构建依赖。从空机器安装到连上外接网关的完整步骤见 [`docs/CLIENT_DEPLOYMENT.md`](docs/CLIENT_DEPLOYMENT.md)。

```bash
pnpm install --frozen-lockfile
pnpm exec tsc --noEmit
pnpm exec eslint src
pnpm run build:vite
cargo check --locked
pnpm tauri dev
```

`pnpm dev` 只启前端开发服务器，跑完整桌宠用 `pnpm tauri dev`。

**Windows**：需要 WebView2、Microsoft C++ Build Tools 和 `stable-x86_64-pc-windows-msvc`。

```powershell
pnpm tauri build --bundles nsis
```

**macOS**：需要 Apple Command Line Tools；捕获全局输入要「输入监控」和「辅助功能」两项权限。DMG 只能在 macOS 上构建。

```bash
pnpm tauri build --bundles dmg
```

调试构建用 `pnpm mac:build-debug`，它在打包后给 `.app` 附加固定的 ad-hoc 签名身份。未签名构建的 designated requirement 是每次编译都变化的 cdhash，macOS 会当成另一个程序，于是每次重建都要重新授权「输入监控」和「辅助功能」。对外分发仍需 Apple Developer 签名与公证。

## 发布

```bash
pnpm run audit:release
pnpm check:docs
```

`audit:release` 扫描待发布资源，`check:docs` 校验版本号、文档里引用的 pnpm 脚本、默认网关地址与代码一致。`.gitignore` 已排除 `*.bongoskin`、ZIP、本地快照、依赖与构建产物；这些检查是辅助防线，不能替代人工确认第三方模型授权。
