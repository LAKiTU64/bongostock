## 当前目标

让用户在偏好设置中直接维护本地自选股票代码，行情面板读取这份列表并按需请求。

## 当前可用流程

```text
偏好设置 → 行情
    ↓
输入 SH600036 或 SZ000858
    ↓
添加 / 删除
    ↓
Pinia + Tauri Store 本地保存
    ↓
短按桌宠打开行情面板
    ↓
按当前自选列表发起一次 Tencent Batch 请求
```

## 代码规则

- 支持 `SH` 或 `SZ` 前缀加 6 位数字；
- 输入会自动去除首尾空格并转换为大写；
- 重复代码不会重复加入；
- 最多保存 20 只股票；
- 空列表合法，面板显示引导且不发起行情请求；
- 当前不提供名称搜索，也不请求搜索接口。

## 行情请求边界

- 打开行情面板时请求一次；
- 点击 `刷新` 时请求一次；
- 面板关闭时不请求；
- 当前不启动自动轮询；
- 当前不做交易日、节假日或交易时段判断；
- 面板中的逐次报价只保存在内存，退出应用后不保存报价。

## 手工检查清单

1. 打开偏好设置 → 行情；
2. 输入 `sh600036`，确认显示为 `SH600036`；
3. 输入错误格式，确认不会加入；
4. 删除全部代码，确认行情面板显示空列表引导且不请求；
5. 添加一只或多只代码，打开行情面板，确认显示对应代码；
6. 点击刷新，确认只产生一次主动请求；
7. 关闭面板，确认不再产生行情请求；
8. 重启应用，确认自选代码仍在。
