# Phase 5 当前功能基线

日期：2026-08-08

## 阶段定义

Phase 5 是 BongoStock 的个人使用 Alpha 稳定化阶段。主要功能已经完成，工作重点从继续扩展功能转为日常使用、修复实际问题和保持文档同步。

## 已实现范围

- Windows 开发环境与 Tauri 运行链路可用；
- 键鼠累计计数、左右拍爪、持久化和 9 位显示上限；
- MMmmmoko Live2D 内置皮肤；StrayRogue 等其他皮肤通过项目外 `.bongoskin` 包导入；
- 桌宠尺寸 50%～300% 连续缩放；
- 矢量三横杠菜单、托盘、置顶、穿透和开机启动；
- Windows 管理员权限说明及不再提示开关；
- 最多 8 个自选分组、总计最多 50 只股票或基金；
- 6 位代码自动识别沪深交易所，在线确认证券名称；
- 新设备默认“自选股”分组，包含上证指数、深证成指、沪深 300、科创 50；
- 双栏紧凑行情浮窗；
- 浮窗拖动、外部点击关闭、临时常驻和 `Esc` 关闭；
- 2 秒默认淡出，时间和透明度可调；
- 行情源可选内置 `stock-api` 或外接 BongoStock API v1，外接支持 HTTP/HTTPS；
- 每次打开时根据桌宠位置自适应生成，不复用旧浮窗坐标；
- 行情仅在打开或手动刷新时请求。
- 点击证券后按需加载分时、5 日和日 K；
- 图表支持悬停读数，显示对应时间/日期与价格，日 K 显示开高低收。

## 当前约束

- 个人项目不建设复杂自动化测试体系；
- 没有安装包、自动更新、代码签名或发布流程；
- 不做后台轮询、周 K/月 K、提醒、AI、MCP 或自动交易；
- StrayRogue/Irox Games 相关本机游戏素材尚未取得再分发许可，仅限项目外的个人皮肤包使用；
- macOS 在最新 UI 与皮肤改动后仍需一次轻量回归。

## 署名规则

- 用户界面中，Live2D 标准模型显示为 `MMmmmoko`；
- 用户导入的皮肤显示其清单中的作者和名称；
- 内部持久化值兼容旧的 `github` 和 `steam`，新内置值为 `builtin:mmmmmoko`；
- 平台名不再作为皮肤的用户可见名称。

## 性能记录

Windows 开发运行、整个 Tauri/WebView2 进程树静置采样：

| 皮肤 | 总 CPU | 私有内存 | 持续 3D GPU |
|---|---:|---:|---:|
| MMmmmoko | 约 2.20% | 约 530.5 MB | 约 1.26% |
| StrayRogue | 约 0.57% | 约 488.8 MB | 未检测到持续占用 |

静态皮肤的 CPU 约低 74%。内存差异较小，主要开销来自预创建的三个 WebView。

## 验证命令

```bash
pnpm exec tsc --noEmit
pnpm exec eslint src
pnpm run build:vite
cargo check --locked
pnpm tauri dev
```

当前阶段不要求建立完整测试框架。若以后修改代码识别、默认数据迁移或分组上限，可针对这些纯数据逻辑补少量单元测试。
- 模型兼容性：内置 `经典小键盘 · 标准模式` 与 `经典小键盘 · 键盘模式` 两套 Awesome-BongoCat 格式模型；原有 `.bongoskin` 自定义皮肤继续可导入。
- 标准模式会合成模型自带的鼠标垫/键盘背景；键盘模式会读取左右键图层并响应全局键盘事件。
