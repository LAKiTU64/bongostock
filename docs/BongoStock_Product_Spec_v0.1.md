# BongoStock 产品方案

> **现状注记（2026-08-11，dev/1.1 迭代）**：本文为 v0.1 历史设计稿。行情数据源已改为**仅外接云端**——客户端不再内置任何本地行情源（已移除 `stock-api` 依赖、东方财富/腾讯公开接口直连），报价/搜索/走势/K 线全部通过用户配置的 BongoStock API v1（Gateway）获取。本文第 2 节“数据源可控”与第 3 节“内置报价依赖”、第 7 节“内置源/外接源”表述不再适用于当前实现。

## 1. 产品定位

BongoStock 是一个 Windows/macOS 桌面宠物：它累计键盘与鼠标操作次数，并在用户主动点击桌宠后展示紧凑的行情/资讯浮窗。桌宠状态下不展示证券信息，行情详情和资讯均按需加载。

当前源码公开于 <https://github.com/LAKiTU64/bongostock>，版本 `1.0.0`。Windows x64 安装包已通过 [GitHub Release v1.0.0](https://github.com/LAKiTU64/bongostock/releases/tag/v1.0.0) 发布，Apple Silicon DMG 本地构建已验证；当前尚未提供代码签名、公证或自动更新。

## 2. 产品原则

- 安静常驻：默认只显示桌宠和累计计数；
- 主动取数：行情面板打开或手动刷新时才拉取报价；
- 详情按需：点击证券后才加载分时、5 日和日 K；
- 本地优先：设置、自选、计数、导入皮肤和本地凭据不通过项目自建账户同步；
- 数据源可控：用户明确选择内置或外接行情源，外接失败不偷偷回退；
- 发布克制：未确认授权的素材不进入源码、Git 历史和公开构建。

## 3. 技术基线

- 桌面框架：Tauri 2；
- 前端：Vue 3、TypeScript、Pinia、Vite；
- 原生层：Rust；
- 模型渲染：PixiJS/easy-live2d 与 PNG 图层；
- 内置报价依赖：`stock-api@2.7.3`，趋势接口带备用源；
- Bundle Identifier：`com.bongostock.desktop`。

## 4. 桌宠与输入

### 4.1 基本行为

- 透明无边框窗口，可拖动、置顶、穿透和调节不透明度；
- 尺寸在 50%～300% 连续调节，默认 100%；
- 全局键盘按下和鼠标点击累计计数；
- 计数本地持久化，显示上限按 9 位数 `999 999 999` 设计；
- 菜单使用独立正方形框和 SVG 三横杠；
- Windows 提供管理员权限说明与“不再提示”开关；
- 支持托盘、开机启动以及将窗口约束在屏幕工作区。

### 4.2 内置模型

| ID | UI 名称 | 作者 | 说明 |
| --- | --- | --- | --- |
| `builtin:mmmmmoko` | 经典小键盘 · 标准模式 | MMmmmoko | 含鼠标垫、键盘、Live2D 猫和按键图层 |
| `builtin:mmmmmoko-keyboard` | 经典小键盘 · 键盘模式 | MMmmmoko | Awesome-BongoCat 兼容键盘模型 |

标准模式按原版坐标系统叠加键位反馈；同一侧猫爪只显示最后按下的一个键。鼠标参数与键盘猫爪参数分离，避免动作错位。模型下方始终保留 BongoStock 计数框和菜单框。

### 4.3 自定义皮肤

- 导入格式：`.bongoskin` 或 ZIP；
- 当前自定义格式：`layered-png-v1`；
- 允许 `manifest.json`、`preview.png`、`assets/` 和 `NOTICE.txt`；
- 图片资源必须为 PNG；
- 压缩包最大 20 MiB，解压总量最大 50 MiB；
- 最多 32 个文件，单文件最大 8 MiB；
- 拒绝绝对路径、父目录穿越和清单外文件；Windows 反斜杠会先规范化；
- 动作猫爪图层在计数框和菜单框上方；
- 导入内容保存在本机，不进入仓库。

旧设置值仅作为本地迁移别名。项目外私人皮肤不在公开源码、Git 历史或构建中；本地学习使用不等于获得再分发许可。

## 5. 行情浮窗

### 5.1 打开与关闭

- 点击桌宠切换独立行情浮窗；
- 首次打开或临时状态回收后按桌宠当前位置重新计算：优先放在下方，空间不足时放上方；
- 浮窗可拖动；外部点击关闭后默认保留模式、详情、筛选和拖动位置 30 秒，期间重新打开或切换模式不重新定位；
- 点击桌宠和浮窗之外区域默认关闭；
- 临时常驻只对本次打开有效；
- `Esc` 始终可以关闭；
- 打开桌宠菜单后再点外部，仍按规则关闭行情浮窗。

### 5.2 布局与淡出

- 第一栏为行情/资讯模式与窗口操作，行情第二栏为横向分组标签，下方为双栏紧凑证券列表；
- 默认 2 秒无操作后淡出到 28%；
- 等待时间可设 1～300 秒；淡出后的不透明度可设 10%～100%；
- 鼠标进入或操作后恢复正常不透明度。

### 5.3 自选管理

- 最多 8 个分组；
- 所有分组合计最多 50 个证券；
- 同一证券不跨组重复；
- 可输入 `SH`/`SZ` 前缀代码或纯 6 位代码；
- 纯代码按首位推断：5/6 归上交所，0～3 归深交所；
- 设置页显示证券名称和统一代码。

全新设备默认只有“自选股”分组：

| 名称 | 代码 |
| --- | --- |
| 上证指数 | `SH000001` |
| 深证成指 | `SZ399001` |
| 沪深 300 | `SH000300` |
| 科创 50 | `SH000688` |

## 6. 行情详情

点击证券后加载详情，支持：

- 分时：四个时间刻度，中午休市/开市处有淡分割线；
- 5 日：首尾交易日期；
- 日 K：首尾日期与 OHLC 蜡烛；
- 鼠标悬停：显示对应时间/日期和价格，日 K 显示 OHLC。

桌宠没有后台持续轮询。报价在浮窗打开或手动刷新时请求；趋势缓存约 30 秒，日 K 缓存约 5 分钟。

## 7. 行情数据源

### 7.1 内置源

- 默认启用；
- 报价按每批 25 个代码请求；
- 日 K 使用 `stock-api`；
- 分时/5 日优先请求东方财富，失败时尝试腾讯备用源；
- 第三方接口可能发生字段、限频、可用性或许可变化。

### 7.2 外接源

- 用户可配置 HTTP 或 HTTPS Base URL；
- 协议为 BongoStock Market API v1；
- 默认超时 8 秒，可设 1～30 秒；
- Bearer Token 可选，保存在本机应用数据中并在重启后自动恢复；
- 只允许同 scheme/host 的 `/v1/` GET/POST 请求；
- 禁止重定向，响应最大 2 MiB；
- 外接失败不会静默切回内置源。

完整接口见[外接行情协议 v1](EXTERNAL_MARKET_API_V1.md)。HTTP 会暴露请求路径、代码与返回内容；HTTPS 可保护传输内容，但网络侧仍可能看到目标主机、时间和流量特征。

## 8. 资讯中心

- 范围：全市场、简报、个股；个股联动本地自选分组与证券；
- 主题：内置预设或一次性的完整自定义检索词；不保存搜索历史和检索词收藏；
- 请求：提供 1 天、3 天、7 天和不限四档时间范围，固定最新优先，并提供约 10 条和约 20 条两个档位；只有点击搜索或刷新时才请求；
- 架构：只访问用户配置的 BongoStock Gateway，不直连上游资讯服务，不保存上游 API Key，不提供本地回退；
- 展示：紧凑列表、已读淡化、同窗口二级详情页、返回导航和系统浏览器打开原文。

资讯与行情源选择相互独立。即使行情使用内置源，只要 Gateway 地址和 Bearer Token 可用，资讯中心仍可工作。

## 9. 设置与持久化

设置页包含：

- 猫咪/皮肤：内置模式、导入皮肤、窗口穿透、置顶、隐藏、缩放；
- 通用：启动项、托盘、主题、语言、Windows 权限提示；
- 行情：分组、证券、关闭后状态保留、淡出参数、数据源、Base URL、超时和连接测试；
- 快捷键；
- 关于：版本、项目地址、日志与第三方说明。

持久化数据包括计数、窗口和行情偏好、自选分组、资讯筛选与已读状态、导入皮肤索引及外接 Bearer Token。包含 Token 的本地配置文件属于敏感数据，不应提交到仓库或公开分享。

## 10. 平台与交付

Windows 开发、debug 构建和 NSIS 安装包已经验证。Apple Silicon DMG 本地构建已经验证；macOS 仍需真机完成输入权限、透明窗口、托盘、置顶、穿透和模型渲染回归，对外分发还需要签名与公证。

当前 Windows x64 安装包已经发布，但尚未签名。继续扩大分发范围或发布 macOS 安装包前至少需要：

- 双平台完整回归；
- 素材、依赖和许可证审计；
- Windows 签名与 macOS 签名/公证；
- 安装、升级、卸载和数据迁移策略；
- 版本发布说明与校验值。

## 11. 当前不做

- 自动交易或券商账户控制；
- 周 K、月 K、技术指标与投资建议；
- 云端账户和自选同步；
- 后台全天轮询与交易日服务；
- 自动更新；
- 将项目外私人皮肤放入公开仓库或安装包。
