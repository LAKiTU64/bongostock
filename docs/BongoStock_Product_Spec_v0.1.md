# BongoStock 产品方案

## 1. 产品定位

BongoStock 是一款供个人使用的 Windows/macOS 紧凑桌宠。它记录键盘按下和鼠标点击次数、对输入做拍爪反馈，并在用户主动点击桌宠时显示自选行情。

核心原则：

- 平时只是一只桌宠，不暴露证券信息；
- 用户需要时才打开行情；
- 行情关闭后不继续请求；
- 无账号、无自建服务端、无后台运维；
- 个人可用和简单稳定优先。

## 2. 桌宠规格

### 2.1 计数与交互

- 统计键盘按下和鼠标点击；
- 左右输入触发对应拍爪图层；
- 计数保存在本机 Tauri Store；
- 计数框按 9 位数设计，最大安全显示值为 `999 999 999`；
- 桌宠可拖动，短按非菜单区域切换行情浮窗；
- 三横杠按钮使用 SVG，按下反馈发生在方框内部。

### 2.2 窗口

- 透明、无边框、可置顶；
- 支持窗口穿透、透明度、托盘和开机自启动；
- 尺寸在设置页以滑块连续调节，范围 50%～300%，默认 100%；
- 字体栈在 Windows 与 macOS 均提供系统字体和等宽数字字体回退。

### 2.3 皮肤

| 内部值 | 用户可见名称 | 实现 | 分发状态 |
|---|---|---|---|
| `github` | MMmmmoko | Bongo-Cat-Mver Live2D 标准模型，由 ayangweb/BongoCat 收录 | 随上游许可证与声明保留 |
| `steam` | StrayRogue | 从用户本机游戏提取的静态 PNG 图层 | 仅限本地使用，暂不公开分发 |

内部值不更名，以免破坏已经保存在本机的设置。用户界面不再显示“GitHub 原版”或“Steam 版”。

## 3. 行情浮窗规格

### 3.1 打开与定位

- 点击桌宠打开/关闭独立 `stock-panel` Tauri 窗口；
- 每次打开都重新读取桌宠位置和浮窗尺寸；
- 水平方向以桌宠为中心；
- 默认放在桌宠下方，空间不足时翻到上方；
- 最终位置限制在桌宠所在显示器的工作区内；
- 用户可以拖动浮窗，但该坐标不作为下一次打开的位置。

### 3.2 关闭与常驻

- 默认点击桌宠和浮窗之外的区域即关闭；
- `Esc` 始终关闭；
- 常驻按钮打开后，本次浮窗不会因外部点击关闭；
- 浮窗关闭后常驻状态清零，下次打开默认为关闭；
- 打开桌宠菜单后再点击外部区域，浮窗仍按上述规则处理。

### 3.3 显示

- 顶部横向分组标签；
- 下方双栏紧凑行情卡片；
- 每项显示名称、统一代码、当前价格和涨跌幅；
- 显示更新时间与刷新按钮；
- 无操作后自动淡出，默认 2 秒；
- 淡出等待时间范围 1～300 秒；
- 淡出透明度范围 10%～100%；
- 鼠标或键盘再次操作浮窗后恢复正常透明度。

### 3.4 详细行情

- 点击证券后才加载详细数据，不在列表页预取；
- 只提供分时、5 日和日 K 三种视图；
- 分时和 5 日图悬停显示时间与价格，日 K 悬停显示日期及开高低收；
- 同一证券的详细数据短时缓存在内存中，详情刷新按钮可强制重新请求；
- 详情请求失败不影响列表报价，详情页提供重试入口。

## 4. 自选与分组

### 4.1 数量

- 最多 8 个分组；
- 所有分组合计最多 50 只股票或基金；
- 至少保留一个分组；
- 同一证券不能跨分组重复添加。

### 4.2 代码输入

- 接受 `SH600036`、`SZ000858`；
- 接受 6 位纯数字代码；
- `5`、`6` 开头默认识别为上海市场；
- `0`～`3` 开头默认识别为深圳市场；
- 支持 `588170`、`589850` 等场内基金；
- 在线匹配时展示证券名称和候选项，由用户确认后加入；
- 设置页同时显示证券名称和统一代码。

### 4.3 默认数据

新设备首次运行创建一个“自选股”分组：

- 上证指数 `SH000001`；
- 深证成指 `SZ399001`；
- 沪深 300 `SH000300`；
- 科创 50 `SH000688`。

用户自行维护过的数据保持不变；全新安装使用上述四个指数。

## 5. 行情请求

- 内置行情源依赖固定为 `stock-api@2.7.3`；
- 也可切换至外接 BongoStock API v1，外接地址支持 HTTP/HTTPS；
- 外接模式默认不自动回退内置源；
- 打开浮窗请求一次；
- 点击刷新再请求一次；
- 使用 loading 锁避免并发重复请求；
- 浮窗关闭后停止请求；
- 点击证券后才请求分时、5 日和日 K 详细数据；
- 详细数据短时内存缓存，详情刷新可强制绕过缓存；
- 不做后台定时轮询；
- 不判断交易日、节假日和交易时段；
- 报价错误不得影响桌宠计数和输入反馈。

## 6. 设置

### 猫咪设置

- 皮肤；
- 窗口尺寸 50%～300%；
- 置顶、穿透、保持在屏幕内；
- 窗口透明度等原有桌宠设置。

### 通用设置

- 开机自启动；
- 任务栏和托盘图标；
- 主题与语言；
- Windows 管理员权限状态和说明；
- Windows“不再提示管理员权限”开关，macOS 不显示该开关。

### 行情设置

- 新建、重命名、删除分组；
- 在线匹配并添加证券；
- 查看名称和代码并删除证券；
- 淡出时间和淡出透明度。

## 7. 本地数据

以下内容通过 Pinia + Tauri Store 保存：

- 累计计数；
- 桌宠皮肤、尺寸和窗口设置；
- 自选分组及代码；
- 行情淡出设置；
- Windows 管理员提示开关。

临时常驻状态和当前行情报价不跨重启保存。

## 8. 性能

Windows 开发运行静置基线：

| 皮肤 | 整个进程树 CPU | 私有内存 | 持续 3D GPU |
|---|---:|---:|---:|
| MMmmmoko Live2D | 约 2.20% | 约 530.5 MB | 约 1.26% |
| StrayRogue 静态图层 | 约 0.57% | 约 488.8 MB | 未检测到持续占用 |

当前预创建三个 WebView，内存主要受 WebView2 进程影响。个人使用阶段不以复杂架构换取有限内存下降。

## 9. 平台与权限

### Windows

- Node、pnpm、Rust MSVC、Microsoft C++ Build Tools 和 WebView2 已配置；
- 普通权限可以运行；
- 部分系统级输入无法捕获时可以管理员身份启动；
- 用户可以关闭管理员权限自动说明。

### macOS

- 需要 Input Monitoring 权限；
- 最新皮肤、缩放、字体和浮窗改动仍需在 macOS 做一次轻量回归。

## 10. 素材与版权边界

- BongoStock 的跨平台底座使用 ayangweb/BongoCat，遵循其 MIT 声明；
- 当前 Live2D 标准模型来源链指向 MMmmmoko/Bongo-Cat-Mver；
- Bongo Cat 原始形象作者为 StrayRogue；
- Steam Bongo Cat 由 Irox Games 开发和发行，官方页面注明其基于 @StrayRogue 的画作与梗图；
- 本项目中的本机游戏 PNG 素材没有单独确认再分发许可，仅限用户个人设备使用；
- 公开 GitHub 或发行构建必须先排除这些素材，或取得明确许可。

## 11. 当前不做

- 自动交易或券商账户控制；
- 周 K、月 K、复杂指标或 Level-2；
- 行情提醒、后台轮询和交易日服务；
- 多数据源容灾；
- AI 分析和 MCP；
- 复杂自动化测试体系；
- 安装包、自动更新、签名和公开发布。

## 12. 当前阶段

项目处于个人使用 Alpha 稳定化阶段。下一步是实际使用、修复真实问题、完成一次 macOS 轻量回归，并保持文档同步。安装包和公开发布由用户以后单独决定。
