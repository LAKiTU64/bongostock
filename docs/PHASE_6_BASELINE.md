## 阶段定义

Phase 6 是 BongoStock 首次公开源码后的个人 Alpha 稳定化阶段。代码已经发布到 <https://github.com/LAKiTU64/bongostock>，默认分支为 `main`；当前仍未发布安装包、签名构建、GitHub Release 或自动更新服务。

Phase 0～5 文档同样保留为历史实施快照。

## 已实现范围

### 桌宠

- Windows/macOS Tauri 透明无边框桌宠；
- 全局键盘按下和鼠标点击累计计数并本地持久化；
- 计数框按 9 位数 `999 999 999` 设计；
- 拖动、置顶、穿透、透明度、保持在屏幕内、托盘和开机启动；
- 50%～300% 连续缩放；
- Windows 管理员权限说明和“不再提示”开关。

### 模型与皮肤

- 内置 `builtin:mmmmmoko`：经典小键盘标准模式；
- 内置 `builtin:mmmmmoko-keyboard`：经典小键盘键盘模式；
- 两套内置模型兼容 Awesome-BongoCat Live2D 目录结构；
- 背景、Live2D 和按键反馈使用原版模型坐标体系，同侧只显示最后按下的键位反馈；
- BongoStock 计数框和 SVG 菜单框保留在模型下方；
- 自定义 `layered-png-v1` 皮肤通过 `.bongoskin`/ZIP 导入；
- 导入器限制为 20 MB 压缩包、50 MB 解压总量、32 个文件、单文件 8 MB，并校验路径和允许的文件类型；
- 导入图层皮肤拍爪时，动作爪层显示在计数框和菜单框上方；
- 未公开的私人皮肤仅存在于项目外的个人皮肤包，不进入源码、Git 历史或公开构建。

### 行情浮窗

- 点击桌宠打开/关闭独立 `stock-panel`；
- 每次打开根据桌宠当前位置重新定位，并限制在当前显示器工作区；
- 双栏紧凑列表、多分组横向标签、拖动、刷新、临时常驻、外部点击关闭和 `Esc` 关闭；
- 最多 8 个分组、合计最多 50 个代码，同一证券不能跨组重复；
- 支持 SH/SZ 完整代码和 6 位纯数字代码；
- 新数据默认“自选股”包含 `SH000001`、`SZ399001`、`SH000300`、`SH000688`；
- 默认 2 秒无操作后淡出至 28%，等待时间范围 1～300 秒，淡出不透明度范围 10%～100%；
- 打开或手动刷新时请求报价，关闭后不后台轮询。

### 详情图表

- 点击证券后才并行请求分时、5 日和日 K；
- 分时/5 日优先东方财富，失败时回退腾讯；
- 日 K 由 `stock-api@2.7.3` 提供，默认显示最近 30 条；
- 分时缓存 30 秒，日 K 缓存 5 分钟；
- 分时显示四个时间刻度和午间分割线；
- 5 日显示首尾日期；
- 日 K 显示首尾日期；
- 悬停显示对应时间/日期和价格，日 K 显示开高低收。

### 行情数据源

- 默认内置源：`stock-api@2.7.3` + 东方财富/腾讯公开走势接口；
- 可切换外接 BongoStock API v1；
- 外接支持 HTTP/HTTPS、Bearer Token 和 1～30 秒超时；
- 外接模式不静默回退内置源；
- Token 保存在本机应用数据中，重启后自动恢复；
- Rust 请求层只允许 GET/POST、配置主机与 `/v1/` 路径，禁用重定向并限制响应为 2 MB。

## 验证基线

```bash
pnpm install --frozen-lockfile
pnpm exec tsc --noEmit
pnpm exec eslint src
pnpm run build:vite
cargo check --locked
pnpm run audit:release
```

Rust 目前包含两项针对皮肤 ZIP 路径标准化的单元测试。项目不建设复杂测试体系；核心迁移、代码识别和安全校验发生明显重构时，再增加少量针对性测试。

## 已知边界

- 最新 UI、模型和行情详情改动仍需在 macOS 做一次轻量实机回归；
- Vite 主包较大，存在非阻塞的 chunk size 警告；
- 行情来自公开接口，可能受网络、限流、非交易日和上游格式变化影响；
- 没有交易日调度、后台轮询、自动交易、周 K/月 K、提醒、AI 或 MCP；
- 公开源码不等于正式软件发布，当前没有用户级安装与升级承诺；
- 第三方模型需要逐包确认授权；未取得再分发许可的素材不得进入仓库或发行包。
